# Web3: 개인 키를 앱이 직접 들고 있지 않게 하기

앱 코드가 키를 읽는 대신 서명을 요청만 하게 바꾸는 것이 목표입니다.

- 운영 서명은 KMS·HSM, 멀티시그(예: Safe), 또는 별도의 서명 서비스로 옮기는 방법을 검토하세요. 앱은 서명할 내용을 서비스에 보내고 결과만 받습니다.
- 개발과 시험에 키가 필요하면 운영과 다른 지갑을 쓰고, 그 지갑에는 필요한 만큼만 자산을 두세요.
- `.env`는 `.gitignore`에 넣고, 저장소에는 값을 비운 `.env.example`만 두세요.

```ts
// 키를 읽는 대신 서명 서비스에 요청합니다 (서비스의 주소와 응답 형식은 예시입니다)
const signature = await signingService.sign({ to, amount });
```

이미 저장소나 로그에 키가 들어갔다면:
1. 새 지갑을 만들어 자산을 옮기고 이전 키는 더 쓰지 않습니다.
2. 이전 키가 권한을 가진 컨트랙트가 있으면 그 권한을 새 지갑으로 바꿉니다.
3. 기록에서 지우는 작업은 그 뒤에 해도 됩니다. 이미 가져간 사본은 되돌릴 수 없습니다.

이 결과가 예시나 시험용 키라면 지문을 `.adkignore`에 적어 무시할 수 있습니다.
