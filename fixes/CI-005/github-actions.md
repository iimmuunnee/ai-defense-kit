읽지 못한 워크플로를 직접 확인하고, 읽을 수 있는 일반 파일로 바꿉니다.

1. 근거에 적힌 파일을 열어 `uses`, `env`, `permissions`, `on`을 눈으로 확인하세요. 링크이면 가리키는 파일을 열어야 합니다.
2. 링크는 저장소 안의 일반 파일로 바꿉니다. 같은 워크플로를 여러 저장소가 써야 한다면 링크 대신 재사용 워크플로를 쓰세요.

```yaml
jobs:
  build:
    uses: <소유자>/<저장소>/.github/workflows/build.yml@<커밋 해시 40자>
```

3. 1MB가 넘는 파일은 재사용 워크플로나 합성 액션으로 나눠 줄이세요.
4. 바꾼 뒤 `adk scan`을 다시 실행해 `CI-001`~`CI-004`가 이 파일에도 적용되는지 보세요.
5. 읽지 못한 이유가 정상이라고 확인했을 때만 이 결과의 지문을 `.adkignore`에 적으세요.
