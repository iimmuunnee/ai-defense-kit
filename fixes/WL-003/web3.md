# Web3: EIP-7702 서명 사용 검토하기

고칠 것이 아니라 확인할 항목입니다. 해당 기능이 의도한 것이라면 지문을 `.adkignore`에 적어 무시할 수 있습니다.

1. 위임 대상 컨트랙트 주소가 코드나 설정에 고정되어 있는지 확인합니다. 요청 값이나 외부 응답으로 바뀌면 안 됩니다.
2. 그 컨트랙트를 검토했는지(감사 보고서, 소스 확인) 기록으로 남깁니다.
3. 체인 ID가 0인 서명은 모든 체인에서 유효하다고 알고 있습니다. 한 체인에서만 쓰려는 서명에 체인 ID를 지정했는지 확인하세요. (EIP 원문과 다시 대조하지 않았습니다. 확인 필요)
4. 서명에 nonce를 어떻게 넣는지 쓰는 라이브러리 문서로 확인합니다. (확인 필요)
5. 운영 지갑 키로 서명한다면, 서명 전에 위임 대상을 사람이 확인하는 단계가 있는지 검토합니다.
6. 위임을 해제하는 절차가 있는지 확인합니다. 해제는 0 주소로 위임하는 서명을 다시 보내는 방식으로 알고 있습니다. (확인 필요)

```ts
// 위임 대상은 코드에 고정합니다 (주소는 예시입니다)
const DELEGATE = "0x0000000000000000000000000000000000000001";
const authorization = await walletClient.signAuthorization({ contractAddress: DELEGATE });
```

위 예시의 매개변수 이름은 viem 버전에 따라 `contractAddress`일 수도, `address`일 수도 있습니다. 쓰는 버전의 문서로 확인하세요. (확인 필요)
