1. 어느 지갑인지, 지금도 쓰는지 확인하세요. 쓰지 않는 지갑이면 자산이 없는지 확인하고, 필요하면 지갑 파일을 외장 저장 장치로 옮긴 뒤 이 컴퓨터에서 지우세요.
2. 쓰는 지갑이면 지갑 프로그램에서 비밀번호(암호화)가 걸려 있는지 확인하세요. 걸려 있지 않으면 거세요. 길고 다른 곳에서 쓰지 않은 비밀번호를 쓰세요.
3. 큰 금액은 하드웨어 지갑이나 이 컴퓨터와 떨어진 지갑으로 옮기고, 여기에는 당장 쓸 만큼만 두세요.
4. 지갑 파일의 백업이 클라우드 동기화 폴더나 문서 폴더에 있지 않은지 확인하세요.
5. 이 컴퓨터가 감염된 것 같다면 파일이 이미 복사되었다고 보고, 깨끗한 다른 기기에서 새 지갑을 만들어 자산을 옮기세요.
