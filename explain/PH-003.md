사용자가 보낸 값이 SQL 문에 바로 들어갑니다(SQL 주입).

왜 위험한가요?
공격자가 입력값으로 SQL 문을 바꿔 데이터를 읽거나 지울 수 있습니다. PHP 공식 매뉴얼은 입력을 SQL 문에 이어 붙이는 것을 원인으로 듭니다.

어떻게 고치나요?
값을 SQL 문과 분리해 전달하는 prepared statement를 쓰세요.

앞에서 값을 이미 검사한 코드일 수 있어 "의심"으로 표시합니다.

이 규칙은 입력이 같은 줄에 바로 들어가는 경우만 찾습니다. 변수에 담아 다른 줄에서 쓰는 코드는 찾지 못하므로, 이 결과가 없어도 안전하다는 뜻은 아닙니다.
